# Noads Browser Android TV upload package

Upload the contents of this folder to a GitHub repository. The included GitHub Actions workflow builds the APK when `android-tv/` changes. Push a tag such as `v0.1.7-tv1` to build the APK and attach it to a GitHub Release.

The ready-to-install debug-signed APK is included at the repository root. For a TV installation, attach that APK to a GitHub Release and open the release asset URL with Downloader or a file manager on the Android TV device.

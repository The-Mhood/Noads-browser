Noads Browser Android TV v0.1.7

APK: Noads-Browser-AndroidTV-v0.1.7-debug.apk

Install from GitHub:
1. Upload this APK to a GitHub Release, not just the source-code page.
2. Open the Release asset URL on the Android TV device with Downloader or a file manager.
3. Allow that installer to install unknown apps when prompted.
4. Install the APK. It includes LEANBACK_LAUNCHER and should appear in the Android TV apps row.

This APK is debug-signed for sideloading. For production distribution or reliable updates,
configure a private release keystore in GitHub Actions and do not commit the keystore.
